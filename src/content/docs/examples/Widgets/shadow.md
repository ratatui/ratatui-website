Demonstrates the [`Shadow`](https://docs.rs/ratatui/0.30.2/ratatui/widgets/struct.Shadow.html)
widget's overlay, block, symbol, and custom rendering modes. Source
[shadow.rs](https://github.com/ratatui/ratatui/blob/ratatui-v0.30.2/ratatui-widgets/examples/shadow.rs).

```shell title=run example
git clone https://github.com/ratatui/ratatui.git --branch ratatui-v0.30.2 --depth 1
cd ratatui
cargo run -p ratatui-widgets --example shadow
```
