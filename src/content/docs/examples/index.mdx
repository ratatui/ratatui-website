title: Examples

These examples are pinned to the Ratatui `0.30.2` release. Each page links to that release's source,
shows the matching run command, and embeds the same source snapshot used by this website.

- [Apps](./apps) are complete, interactive programs from upstream `examples/apps`.
- [Layout](./layout) collects applications focused on constraints and layout behavior.
- [Style](./style) collects applications focused on colors and text modifiers.
- [Widgets](./widgets) are smaller, focused examples from upstream `ratatui-widgets/examples`.
